# 메타시간표 v6 — 알림·테마·전날 완료

## 실제 사용자 요청

알림을 받고 싶은 시각 설정, 테마 색 변경, 월~일 한 줄 표시 및 지난 날짜 비활성화, 실제 마감 전날까지 완료하는 계획, 공지 분석 개선을 요청했다. 참고 사이트 주소를 받았으나 Vercel 로그인 화면만 확인했고, 사용자가 참고 사이트는 넘어가자고 했다. 참고 사이트의 기능을 확인하거나 복제했다고 주장하지 않는다.

## 구현 판단과 결과

- 알림: 최대 3개 시각과 요일 선택. 정기 알림·마감 30분 전·5분 타이머를 각각 설정. 개인 프로필로 계정에 보관하되 브라우저 알림 권한은 기기별 허용. 사이트가 열려 있을 때만 발송하며 절전·종료 상태 발송을 보장하지 않는다. 시간대는 사용하는 기기 기준. 2분 이내 지연만 허용하고 같은 시각은 반복 발송하지 않는다. 실제 OS 수신은 테스트 알림으로 사용자가 확인해야 한다.
- 테마: 밝게/어둡게/기기 설정, 5개 강조색, 직접 고르는 강조색·배경색. 명도에 따라 검정/흰색 글자를 선택한다. 다크 화면 검수에서 요약·저장 상태·숫자 배지의 남은 고정색을 수정했다.
- 주간 표시: 월~일 7칸. 과거 날짜는 회색 disabled. 14일 계획은 앞뒤를 비활성 날짜로 채워 온전한 주 단위로 표시한다. 모바일의 주간 여유 시간은 가로 스크롤 없이 7칸을 보여준다.
- 마감 정책: 저장된 실제 마감일·시각은 보존하고 완료 목표만 하루 전으로 계산한다. 오늘 마감인 미완료 항목은 목표 경과로 경고하며 마감 당일에 몰래 배치하지 않는다. 옛 직접 계획이 정책과 충돌하면 경고하고 저장값을 임의 삭제하지 않는다.
- 공지: 날짜 변경(에서/화살표/아니라), 날짜 머리말, 여러 줄·세미콜론 분리, 약칭·글피·N일 후 등을 보강. 미적분·기하 같은 제목 구분은 유지하고 과목만 수학으로 분류한다. 원문을 보존한다. 두 요일 중 택일·부정·취소 표현은 확인 대상으로 남긴다. 유사도는 규칙 기반 비교이지 학습된 정확도 수치가 아니다.
- 검토 화면에서 제목·분류·과목·실제 마감·소요 시간을 수정할 수 있다. 기존 진행·메모를 보존하며, 연결 후보를 선택해도 다른 행에서 편집한 값은 유지한다.

## 검증 증거 (배포 전)

검증 스킬에 따라 화면→API→데이터→새 로그인 복원 경계를 점검했다. agent-browser 실행은 CDP 연결 오류로 실패했으며 CUA로 개발 화면 로딩을 확인하고, 자체 앱의 격리된 Playwright 테스트로 기능을 검증했다.

- `npm test`: 120개 통과. 기존 당일 배치 테스트는 새 전날 완료 정책에 맞춰 바꾸고 실제 마감 유지·윤년·주 경계·잘못된 설정·모호한 공지 사례를 추가했다.
- 브라우저 기존 기능 회귀: 29개 통과. 공지 변경·중복·메모·초안·실시간 시계·자정 갱신.
- 새 화면 기능: 20개 통과. 테마 저장/새로고침, 알림 시각/요일, 테스트 어댑터 발송/중복 방지, 모바일 7칸, 공지 수정.
- 실제 테스트 계정/Neon API: 56개 통과. 가입/로그인, 설정 저장, 새 브라우저 복원, 계정 격리, 잘못된 테마/시각 거부, 메모/진행/계획 보존. 이 실행에서 생성한 가상 계정과 작업 공간만 삭제하고 삭제 확인했다. 실제 사용자 계정은 삭제하지 않았다.
- 총 225개 검증 항목 통과. OS 알림 실수신, 닫힌 브라우저 발송, 모든 자연어의 완벽한 해석을 검증했다고 주장하지 않는다.

## 제출 설명 후보

실제 사용자 요구가 ‘마감 당일 허용’에서 ‘전날 완료’로 바뀌자 실제 마감과 계획 목표를 분리하고 테스트를 변경했다. 기능 수만 늘리는 대신 단일 입력과 확인 가능한 해석을 유지했다. 유료 AI/API나 유료 예약 발송 서비스를 추가하지 않았다. 공개 배포의 최종 상태는 별도 배포 확인 기록에 남긴다.
