# 요청과 개선 과정

사용자 요청: 등록된 할일 삭제, 같은 학교·반 그룹 자동 추가.

할일 목록과 수정 화면에 확인 절차가 있는 삭제를 추가했다. 새 메뉴 없이 기존 화면에서 처리한다. 할일의 계획·기록도 제거하고 재계산한다. 이미 공유된 채팅은 상대방 기록이므로 유지하도록 안내한다.

자동 그룹은 기존 학급 인증과 공개 동의를 유지하면서 별도 생성/초대를 없앴다. 미인증 학교 이름만으로 학생 대화에 들어갈 수 없도록 서버의 인증 소속을 사용한다. 공개 해제 때 오래된 참여자 목록으로 접근하는 문제를 막기 위해 자동 그룹 권한은 매 요청마다 계산한다.

기존 DB에는 nullable 컬럼과 유니크 인덱스만 추가했다. 기존 사용자의 staged .gitignore 변경은 별도로 보존한다.

단위 검사 136개, 구문 검사, 빌드 통과. 로컬 브라우저 → API → Neon DB → 재접속 검증 39개 통과. 삭제 확인 취소/확정, 재접속 유지, 공유 사본 보존, 동시 그룹 생성, 같은 학교·반 연결, 다른 반·학교 차단, 공개 해제/재설정, 학급 해제, 차단 메시지 숨김, 기존 개인 대화 검사 포함. 테스트용 학교·계정·그룹만 정리했고 실제 사용자 자료는 수정하지 않았다.

운영 배포 최종 결과는 워크스페이스 outputs의 v7.2 배포검증 보고서에 기록한다.
