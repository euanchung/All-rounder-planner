# v8 실제 제작 기록

요청: 관리자 전체 회원 관리, 승인된 선생님·반장·부반장만 공지/할일 공유, 역할별 화면, 주간 시간 막대, 현재 수업과 야자, 학교별 직접/사진 시간표, 이전 로고와 ‘시간을 아끼다, 메타시간표’ 문구.

불명확한 ‘학생 공부 비활성화’는 개인 학습 차단이 아니라 공지 게시/할일 공유 차단으로 해석했다고 알렸다. 사용자는 이전 로고를 기억하지 못한다고 답했으며 Git 기록의 달력 M 로고를 복원했다.

구현: 서버 권한과 정지 검사, 관리자 전용 API/화면, 신청과 실제 권한 분리, 공유 빈도 제한, 주간 비율 막대, 한국 시각·자정 넘김 일과, 사진 분석 초안/본인 이력, 수동 수정과 학교 예시. 개인 데이터·API 키·사진 속 교사 이름을 저장소에 넣지 않았다.

수정 과정: 실제 인증 user.id(uuid)와 앱 user_id(text)의 조인 오류를 통합 검사에서 발견해 명시적 캐스팅으로 수정. 시간표를 불러오기 전에 검사하던 테스트는 응답 후 UI가 나타나도록 기다리는 방식으로 수정. 브라우저 도구 CDP 실행 실패 뒤 Playwright로 대체해 시각·API·DB 흐름을 확인했다. 관리자 UI 시각 검사는 데이터/권한을 대체한 명시적 fixture이며 실제 소유자 로그인 성공으로 과장하지 않는다.

검증: 단위 155개 통과, 통합 67개 통과, 합성 계정의 직접 시간표 저장/새로고침·역할 신청·관리 화면 표시 확인. 제공 시간표의 현재 6교시와 야자 행, 일~토 막대를 데스크톱/모바일 캡처로 확인했다. 실제 Gemini 사진 API 503으로 자동 추출 성공 미검증; 실패해도 수동 입력값이 유지되는 것 확인. 무한 재시도나 유료 전환 없음.

화면 증거는 작업공간 outputs/v8-login.png, v8-home.png, v8-week.png, v8-mobile.png, v8-admin-fixture.png에 보관한다. 테스트 계정·메시지만 삭제했으며 실제 회원 데이터는 보존했다.
