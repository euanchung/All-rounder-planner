# 메타시간표 v5 · 인증 간소화 / 공지 자동 대조 / 용어·시각

## 사용자의 수정 요청

가입·로그인은 유지하되 가입 이메일 확인을 없애고, 지정한 기존 계정에 관리자 권한 부여. 공지 비교의 연결할 과제 선택란 삭제 후 붙여넣기만으로 기존 할일 수정/신규 추가를 판단. 현재 날짜·시각을 반영. 용어는 일일 시간, 소요 시간, 남은 시간으로 통일하며 할일은 공부와 과제의 합으로 정의.

## 구현 판단과 결과

- 관리자는 기존 계정의 불변 user ID에 일회성으로 연결. 이메일 확인 상태를 바꾸거나 로그인 시 이메일만 비교하여 자동 승격하지 않는다. 계정별 JWT·서버 검증과 관리자 403 처리는 유지한다. 실제 이메일·계정 ID는 기록/저장소에서 제외했다.
- 계정 화면의 이메일 확인/인증번호 전송 제거. 일반 이메일·비밀번호 가입·로그인·개인 저장은 유지. 비밀번호 재설정에는 별도의 소유 확인이 필요하여 메일 복구를 유지했고, 미수신 한계를 안내했다. SMTP 설정은 변경하지 않았다.
- 공지 입력은 본문만 필수. 기본 작성일은 오늘이며 예전 공지의 작성일만 선택사항으로 변경한다. 붙여넣은 내용을 제목·과목·분류 유사도로 기존 항목과 대조해 수정 또는 신규 추가 제안. 비슷한 후보, 취소, 여러 날짜는 확인 대상으로 남긴다. 마지막 한 번에 반영하며 진행·메모·직접 계획·생략된 필드는 보존한다.
- 날짜 변경의 ‘A에서 B’, ‘A → B’는 B를 읽는다. 임의 문장을 모두 이해하는 AI가 아닌, 기기 내 무료 규칙 기반 해석이라고 표시한다. 원문/기록이 분석 이후 바뀌면 다시 분석하도록 하여 오래된 초안 덮어쓰기를 막는다.
- 공부/과제를 분리 저장. 과거 혼합 study 분류는 제목으로 재해석하며, 이후 명시적 선택은 kindVersion으로 보존. 준비물·구매 등 생활 항목은 목록에 남기되 학업용 일일 시간을 자동 소비하지 않는다.
- 현재 시각/마감 카운트다운을 표시. 일일 시간에서 오늘 진행한 시간을 빼고 자정까지의 실제 남은 분으로도 제한. 명시된 마감 시각 전까지로 추가 제한한다. 자정/탭 복귀/분 변경 때 계획·과부하를 갱신하되 입력창·초안·포커스는 유지한다.
- 남은 시간(작업량)은 소요 시간 − 진행 시간. 시간이 흐르는 것만으로 완료한 것처럼 줄이지 않는다. 수업/휴식의 시간대를 자동으로 알지는 못하므로 일일 시간을 사용자가 조정해야 한다.

## 실제 검증 과정

- 기존 72개 테스트에 공지 자동 연결·신규·애매함·중복·취소·이력/메모 보존, 구체적 시각/자정, 분류 이관, 가입 확인 UI 제거 검증을 추가: 단위 테스트 99개 통과.
- 이전 한 줄 입력/메모/수정/직접 계획/날짜 시간 조정/모바일 7칸/캘린더 검증 24개 통과.
- 새 공지 흐름과 편집·초안 복원, 모바일, 시간 경과·자정·포커스 유지의 브라우저 검증 29개 통과.
- 실제 Neon 테스트 계정 2개로 인증 없는 가입, 재로그인, API→DB 저장·복원, 공지 변경, 계정 격리·관리자 거부·유효성·충돌 검증 49개 통과. 합계 201개 체크(서로 다른 실행 환경에서 재실행한 것은 중복 합산하지 않음).
- 테스트용 계정/워크스페이스만 정확한 생성 이메일·ID로 정리하고 부재 확인. 실제 사용자 기록은 삭제하지 않았다.
- agent-browser는 CDP 연결 오류로 실패하여 기존 격리 Playwright/Edge 테스트 브라우저를 사용. 사용자 로그인 브라우저를 우회 조작하지 않았다.
- 테스트 기대값 오류 두 개(기존 수정 이력 수, 점수 정렬 후 마지막 항목을 시간 테스트 대상으로 가정)를 수정했다. 각각 정확한 초기 이력과 할일 ID를 기준으로 다시 검증했다.

## 한계와 제출 설명

메일 전달 장애 자체, 비밀번호 재설정 메일 수신, 실제 휴대폰 OS 알림 수신은 이번 변경에서 해결/검증했다고 주장하지 않는다. 공지 자동 대조의 정확도를 실제 사용자 데이터로 수치화하지 않았다. 수학 문제풀이 도구는 기존 범위를 유지한다. 유료 서비스는 추가하지 않았다.
