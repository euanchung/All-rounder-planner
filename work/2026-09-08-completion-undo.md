# 완료 취소 후 계획 복구

- 요청: 완료를 취소하는 순간 시간표·주간 계획에 다시 반영.
- 원인: 완료 버튼은 남은 시간을 진행 기록에 추가했지만 취소는 done만 변경해 작업량이 0으로 남았다.
- 수정: 완료 직전 진행량과 수동 배치, 자동 완료 기록 ID를 저장. 취소 시 해당 기록만 되돌리고 다시 계획 계산 및 저장. 이전 버전의 완료 기록은 마지막 진행 기록을 통해 복구. 기록이 없는 0분 완료 상태는 총 작업량을 기준으로 복구하므로 사용자가 진행 시간을 확인해야 한다.
- 기존 마감·가용 시간 제약은 유지: 이미 마감된 일이나 가용 시간이 없는 일은 무리하게 일정에 배치하지 않는다.
- 검증: Node 테스트 242개 통과, build/check 성공. 로컬 가상 사용자 브라우저 7항목 통과: 완료, 부분 진행 복원, 주간 계획, 새로고침 유지, 메인 화면 복원, 오류 없음, 외부 회원 생성 없음.
- 저장 흐름: queueSave → /api/workspace PUT → validateBackup → 기존 JSON 데이터 저장. 복구 메타데이터도 검증 및 보존.
- 캡처: outputs/completion-undo-week-local.png, outputs/completion-undo-home-local.png (저장소 바깥). 실제 운영 계정 화면이 아닌 로컬 목 데이터, 고정 테스트 시각 사용. 과거 화면 재현으로 오인하지 않도록 표시.
- 브라우저 기본 도구 CDP 실행 실패로 번들 Playwright/Edge 대체 사용.
