# 주소 전환 및 관리자 강제 탈퇴

- 사용자 요청: 친구의 해킹 주장 후 주소 변경, 회원 관리에 강제 탈퇴 추가. 추가 설명은 '서버 시간을 바꿨다'이며 침해는 아직 확인되지 않았다.
- 읽기 전용 확인: 22:07~22:10 KST 시점 DB now(), 웹 Date 응답, 검증 기기 UTC가 일치. 관리자 1명. 최근 감사에는 시간표·대화 열람이 있었지만 이것만으로 불법 접근을 판별할 수 없다. 현재 화면 시간은 접속 기기의 Date 기반이므로 기기 시간 변경으로 화면/계획이 달라질 수 있다.
- 호스팅: 새 대표 도메인 연결, 이전 대표 및 자동 보조 별칭 2개 제거, 프로젝트 이름 변경으로 이전 자동 이름 재생성 방지. 고유 배포는 기존 Vercel 인증 보호 유지. 주소 변경은 세션 취소나 침해 해결을 의미하지 않는다. 인증 서비스 새 Origin get-session/CORS 응답 확인.
- 기능: 관리자 ID/권한 서버 검증 후 확인 문자열을 요구하여 비관리자 계정만 강제 탈퇴. 본인/관리자는 보호. 개인 작업공간·프로필·AI 기록·푸시·참여 제거, 담당 학급 폐쇄. 공유 대화·공지·감사 보존. 모든 변경은 DB 트랜잭션. Auth user 삭제에 session/account가 CASCADE인 것을 실제 DB 메타데이터로 확인. 이후 API는 존재하지 않는 사용자 거절.
- 강제 탈퇴는 재가입 영구 차단 기능이 아니다. 특정 회원 삭제는 실행하지 않았다.
- 검증: 자동 테스트 252개, 로컬 목 사용자 UI 5항목 통과. 운영 게스트 관리자 API 401 확인. DB 삭제 테스트는 목 DB이며 실제 사용자 생성/삭제 없음.
- 캡처: 저장소 밖 outputs/admin-force-remove-local.png, 로컬 가상 데이터 표시. 기본 agent-browser CDP 실행 실패로 Playwright/Edge 사용.
