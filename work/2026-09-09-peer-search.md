# 소통 사용자 검색 개선

요청: 관리자에게는 가입 회원이 보이지만 소통에서 이름 검색이 되지 않음.

## 확인 및 변경

- 운영 데이터는 개인정보 없이 집계만 조회. 가입자 중 초기 설정 미완료 및 비공개 프로필이 있으며 공개 회원도 서로 다른 학교에 분산됨. 관리자 목록과 검색 디렉터리는 범위가 다름.
- 같은 학교·양쪽 공개 동의·차단·정지 제외 조건 유지. 실제 회원 설정 변경 없음.
- 소통 화면에 검색 대상 학교와 본인 공개 상태, 명시적 동의 버튼, 설정 이동 및 검색 목록 새로고침 추가.
- 검색어를 화면 상태에 보존. 자동 갱신이 입력 중 포커스를 빼앗지 않게 수정.
- 이름 띄어쓰기·ID 대소문자·전각 문자 정규화. 초기 설정/학교/공개/표시 이름을 확인하도록 빈 결과 안내 개선. 학급 가입이 필요하다는 잘못된 안내 제거.

## 검증 및 캡처

- 전체 자동 테스트 256개, 빌드 및 구문 검사 통과.
- 로컬 모의 계정으로 동의 전 차단, 명시적 동의 요청, 검색, 새로고침·페이지 이동 후 검색 유지, 1:1 대화 진입 검증. 실제 계정 생성 및 메시지 전송 없음.
- 프로젝트 바깥 outputs/peer-search-before-local.png, peer-search-after-local.png, peer-search-consent-local.png 저장. 모두 2026-09-09 촬영한 로컬 재현 화면이며 화면 시계는 테스트 고정 시각임. 과거 작업 당시 캡처나 운영 회원 화면으로 표현하지 않음.
- 실사용자 양쪽 계정 로그인 검색은 사용자 확인 필요. 이번 변경은 공개 동의를 우회하지 않으므로 양쪽 초기 설정·학교·공개 동의를 확인해야 함.
