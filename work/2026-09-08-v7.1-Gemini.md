# v7.1 — Gemini 실제 연결

## 요청과 변경

- 사용자 요청: 공급자 제한 안내 후에도 실제 Gemini 연결과 배포 진행.
- Gateway 대신 Google 직접 연결. 모델 목록에서 gemini-3.8-flash 확인, 설치한 AI SDK 7 / Google provider 4 문서와 구조화 출력 방식 확인.
- 키는 서버 Secret으로만 등록. 새 설치 기본값은 비활성화. 키가 없으면 활성화 플래그만으로 켜지지 않음.
- 기존 1인 하루 5회 / 사이트 하루 30회 / 월 40회 제한 유지. 실패 포함, 저장 답변 재사용은 추가 차감 없음.
- Google 무료 서비스 입력·출력 이용 안내와 전송 동의 강화. 사진은 일시 전송만 하고 앱 DB에는 원본 미보관.
- 공급자 429 오류와 연결 오류를 구분. 상세 공급자 오류·키·질문·사진은 서버 오류 로그에 출력하지 않음.
- 나이 확인이나 공급자 안전장치 우회 없음. 약관의 학생 대상 제한은 해결되지 않았으며 공급자 승인/학교 도입 승인을 받았다고 주장하지 않음.
- 결제·자동 충전·유료 전환 설정 없음. 추정 비용은 공개 단가 비교용이며 실제 청구액이 아님.

## 검증

- 단위 검사 132개 / 구문 검사 / 빌드 통과.
- 실제 로그인·학급·채팅·계획 및 AI 생성·본인 답변 재조회·다른 계정 조회 거절: 43개 통과.
- 공개 빌드에서 Gemini 키 미포함 검사 통과.
- 고정 응답이 아닌 Gemini 실응답을 사용. 테스트용 계정·자료만 정리하고 실제 사용자 자료는 변경하지 않음.
- 상세 사진·화면 검증과 운영 배포 결과는 워크스페이스 outputs의 v7.1 배포검증 보고서에 기록.

## 남은 운영 제약

공급자 학생 대상 제한, 무료 입력의 제품 개선·검토 가능성, 계정별 무료 한도, 학교의 개인정보 안내·승인 절차는 별도 검토가 필요하다. API 키만으로 계정 결제 상태를 확인할 수 없으므로 무조건적인 무과금을 보증하지 않는다.
