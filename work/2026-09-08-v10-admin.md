# v10 작업 기록

요청: 관리자 별도 링크, 관리자가 역할 지정, 코드 없는 소속 학급, 승인된 공개/코드 그룹, 자동 가입 제거, 탈퇴/추방/폐쇄와 관리자 대화 열람.

판단: 마지막 학급 규칙을 우선한다. 관리자 링크에 기존 계정 인증과 서버 권한 검사를 유지한다. 비밀번호 원문 열람은 구현하지 않는다. 관리자의 모든 대화 열람 사실을 사용자에게 알린다. 그룹에서는 학생 공유를 허용한다. 폐쇄는 복구 가능한 기록 보존 방식으로 구현한다.

도구 영향: Vercel 배포/브라우저 검증 스킬에 따라 빌드·브라우저·API/DB 경계를 확인. agent-browser CDP 실패로 설치된 Edge/Playwright 가상 클라우드 검증으로 대체. 테스트 회원 생성 없음.

결과: 199개 자동 검사, 18개 새 화면 검사, 14개 회귀 화면 검사. 실제 DB 조회 성공. 배포 후 공개 링크와 관리자 인증 차단을 별도 확인한다.
