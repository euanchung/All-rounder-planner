# 시간 입력·복사와 날짜 인식 개선

- 사용자 요청: 자습 구간 타이핑, 요일 사이 복사·붙여넣기, 내일/이번주 목요일/다음 화학 시간 인식 오류 수정.
- 원인: 한 줄의 날짜 또는 날짜+숙제까지 다중 공지의 날짜 머리글로 분류하여 입력에서 누락했다. 다음 수업은 과목으로 마감 검색은 가능했으나 표현 제거와 인식 표시가 없었다.
- 수정: 실제 다중 공지 머리글만 구분하고 단일 날짜·짧은 과제는 유지. 다음 과목 수업은 현재 시각 이후 시간표 검색 및 인식 표시. 시간표에 없으면 확인 안내를 유지.
- 시각 입력: 19:30/1930/19 → 표준 HH:mm. 부정확한 시각·중복·야자 겹침은 기존 검증으로 차단. 요일별 전체 구간 복사와 붙여넣기, 기존 구간 덮어쓰기 확인. 원본과 복사본은 독립적이며 저장 버튼으로 적용.
- 검증: 자동 테스트 249개, 브라우저 로컬 검증 12항목(타이핑, 복사, 독립 편집, 저장 후 복원, 날짜 표현, 다음 화학 14:10 수업, 인식 칩, 연속 입력, 오류/외부 회원 생성 없음).
- 브라우저 스킬 기본 도구 CDP 실행 실패로 번들 Playwright/Edge 대체. 운영 사용자 대신 목 데이터/고정 시각 사용.
- 캡처: 저장소 밖 outputs/time-copy-local.png 및 outputs/date-recognition-local.png. 포트폴리오에는 로컬 검증 화면이라고 표기.
