# 시간표 사진 입력 오류 수정

요청: 기존 캡처 보관 후, 시간표 사진 업로드의 AI 분석 실패 해결.

- 기존 출력 이미지 39개를 별도 capture-archive 폴더로 복사하고 SHA256 일치를 확인했다. 원본은 유지했다.
- 실제 Vercel /api/schedule 로그에서 Gemini 3.8 Flash 503을 확인했다.
- 제공된 JPEG로 직접 검증했다. 2.5 Flash는 모델 목록에 있지만 실제 요청은 404였다. 최종 시간표 전용 모델은 실제 성공한 Gemini 3.5 Flash이다. 공부 도우미 모델은 변경하지 않았다.
- 동일 모델 최대 2회, 전체 49초 제한. 재시도마다 기존 사용자/사이트 예산 제한을 적용한다. 결제 설정은 변경하지 않았다.
- 읽을 수 있는 과목과 유효한 일과는 보존하고 겹치는 잘못된 일과는 확인 경고와 함께 제외한다. 명시된 병합 활동만 빈 교시에 채운다.
- 실사진 분석 성공: 약 13초, 5요일 × 9교시, 일과 19개. 자정 이후 종료도 보존. 작은 요일 범위(화~목)는 모델이 화·목으로 읽었으므로 저장 전 확인이 필요하다. 모든 OCR이 정확하다고 주장하지 않는다.
- 결과를 요청자의 기존 관리자 계정에 분석 기록으로 저장했다. 학교/학급 시간표를 자동 덮어쓰지 않았다. 실제 테스트 회원은 생성하지 않았다.
- 실제 AI 결과를 로컬 모의 계정 UI에 연결하여 사진 업로드 → 분석 중 버튼 → 과목/일과 반영 → 오류 안내/입력 유지 10개 검증 통과. 이 캡처는 실서비스 로그인 화면이 아닌 실 AI 결과의 로컬 UI 재생이다.
- 사진 원본, 회원 정보, API 키는 저장소에 포함하지 않는다. 캡처와 원본 분석 JSON은 비공개 로컬 outputs에 보관한다.
- 공식 모델 무료 등급/참고 단가: https://ai.google.dev/gemini-api/docs/pricing (2026-09-08 확인).
