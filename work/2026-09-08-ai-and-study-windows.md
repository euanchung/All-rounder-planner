# AI 연결과 실제 자습 구간 기반 일일 시간

## 사용자 요청

시간표 사진 분석과 공부 도우미의 AI 오류를 함께 해결한다. 요일별 분 수 대신 여러 시작/종료 구간을 받아 일일 시간과 현재 남은 일일 시간을 계산한다.

## 발견과 수정

- 기존 개인 5회 제한은 시간표와 도우미가 공유했고 실패·개발 검증도 차감했다. 새 개인 한도는 기능별 5회로 구분하고 전체 요청 실패 시 개인 예약을 복구한다. 사이트 호출 예산은 실패/재시도에도 계속 차감한다. 성공 기록은 새 개인 카운터로 이관한다. 전체 예산 카운터를 초기화하지 않는다.
- 실제 Gemini 3.8 및 3.5에서 503이 재현됐다. 도우미는 실제 응답이 확인된 3.1 Flash-Lite → 3.5 Flash, 사진은 3.5 Flash → 3.1 Flash-Lite 순서로 최대 2회, 전체 49초로 제한한다. 과금 설정이나 자동 충전은 변경하지 않는다.
- SDK 결과의 getter를 객체 spread로 잃지 않도록 output/usage를 명시적으로 반환한다.
- 개념 설명 실호출 4,750ms 성공, 방정식 문제 3,612ms 성공, 시간표 사진 실호출 13,477ms 및 일과 19개 성공. 외부 모델은 혼잡/무료 쿼터/인증/사진 품질에 따라 실패할 수 있으므로 무조건 성공을 주장하지 않는다.
- 진단은 인증 회원을 만들지 않으며 별도 진단 식별자로 사이트 예산만 사용한다. 실제 학생의 개인 한도와 시간표/과제를 변경하지 않는다.
- 자습 구간은 요일별 최대 12개. 중복, 잘못된 시각, 하루 12시간 초과를 검사한다. 빈 요일은 0분. 23:40~00:50은 20분/50분으로 실제 달력 날짜에 나눈다.
- 남은 시간은 한국 현재 시각 이후의 구간만 합산한다. 쉬는 시간과 이미 끝난 구간은 제외한다. 과제 진행 기록은 과제 작업량만 줄이며 지난 시간을 다시 이중 차감하지 않는다.
- 기존 분 단위 값은 백업에 유지하되 임의의 시각으로 변환하지 않는다. 사용자가 설정에서 구간을 등록하기 전에는 해당 시간을 계획에 쓰지 않는다.
- 특정 날짜의 구간 변경/요일 기본값 복원도 지원한다. 서버 저장 데이터 검증에도 구간과 자동 계산 분 수의 일치를 적용한다.

## 검증과 캡처

- 자동 테스트: 시각 전/중/후, 구간 사이 휴식, 야자 자정 경계, 토→일, 미래/과거, 날짜 예외, 중복, 프로필 검증, 계획 연결, 실패 복구, 모델 전환.
- 로컬 UI 16개 검증: 구간 추가/삭제, 잘못된 구간 저장 차단, 초안 페이지 이동, 저장/재로드, 주간 막대, 특정 날짜 변경/복원, 모바일, 실제 AI 응답의 개념/3단계 표시.
- outputs/v12-study-windows-local.png, v12-study-windows-mobile-local.png, v12-ai-answer-local.png는 모의 회원 + 고정 검증 시각(2026-09-08 19:30 KST) + 실제 AI 응답 재생이다. 실서비스 로그인 캡처로 표기하지 않는다.
- 기존 캡처 보관본은 유지했다. 사진 원본, API 키, 실제 개인정보는 GitHub에 올리지 않는다.
- Vercel 생산 환경의 AI 활성화 및 키 설정 존재를 확인했다. 민감한 키 값은 플랫폼이 마스킹하므로 로컬 값과의 일치 여부를 직접 비교하지 않았다.
