# v10 · 관리자와 학급·그룹 분리

- 일반 사용자: `/`, 관리자: `/admin`. 동일한 이메일·비밀번호 로그인, 추가 인증 없음. 서버는 기존 소유자 UUID만 관리자로 허용한다. 비밀 URL 자체를 권한으로 사용하지 않는다.
- 비밀번호 원문·해시는 관리자 응답에 포함하지 않는다. 이름·이메일·학교·학년·반과 역할만 회원 화면에 표시한다.
- 모든 새 사용자는 학생. 반장·부반장·선생님은 관리자만 지정한다. 이전 역할 신청/선생님 승인/선생님의 임원 지정 API는 차단한다.
- 학급: 선생님 개설, 동일 소속만 코드 없이 직접 입장. 역할에 관계없이 탈퇴 가능. 담당 선생님 탈퇴/역할 해제 시 학급 폐쇄. 선생님과 관리자 추방 가능.
- 그룹: 누구나 개설 신청, 관리자 승인 후 개설. 공개 또는 개설자가 정한 8~64자 코드. 선택적으로 같은 학교만 참여. 자동 가입 없음. 개설자도 승인 후 직접 입장한다.
- 일반 학생에게 공지·할일 공유 버튼을 표시한다. 학급 공유/공지 시도는 권한 팝업과 서버 403. 그룹 회원은 역할 제한 없이 공유할 수 있으며 과도한 요청 방지 제한은 유지한다.
- 관리자: 회원 역할, 학교·반 시간표 조회, 모든 대화 조회, 그룹 승인/편집, 학급 담당자·소속 편집, 폐쇄/추방/재입장 제한 해제만 제공한다. 개인 계획·프로그램 설정 메뉴 없음.
- 폐쇄는 접근 차단과 회원 탈퇴이며 데이터 삭제가 아니다. 대화는 관리자 열람을 위해 보존한다. 관리자 대화 열람은 감사 기록에 남는다. 회원가입·설정·소통 화면에 개인 대화 포함 관리자 열람을 안내한다.
- 그룹 코드는 salted scrypt로 저장하고 회원/API 목록에 반환하지 않는다. 비밀번호 입력 폼은 초안에 저장하지 않는다.

## 검증

- 단위/회귀 199개 통과. 새 로컬 브라우저 흐름 18개, 기존 화면 회귀 14개 통과.
- 운영 인증 계정을 생성하는 테스트는 실행하지 않았다. 가상 클라우드 브라우저 테스트는 외부 인증/DB 호출이 0건이다.
- 실제 DB: 관리자/공간/시간표 조회, 소속별 디렉터리 쿼리와 새 테이블 RLS 확인. 기존 관리자 개인 할일 2개 보존.
- 운영 DB의 변경은 추가 스키마와 이전 자동 그룹의 명시적 가입 전환이다. 사용자 계정 삭제 없음.
- 실제 두 회원의 기기 간 송수신과 기기 푸시 수신은 이번 검증에 포함하지 않았다.
