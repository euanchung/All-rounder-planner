# v7 — 학교 연결형 메타시간표

## 화면과 이용 흐름

1. 메인: 오늘까지 끝낼 일(남은 시간/소요 시간), 반 게시판·급식, 1~9교시 시간표, 월간 마감 달력의 네 영역.
2. 할일 추가: 한 문장 자동 분류 후 내용 옵션·미니 시간표·달력에서 확인하고 추가. 공지 여러 줄은 일괄 초안으로 만들어 최종 클릭 전에는 저장하지 않음. 기존 할일 편집·메모·진행 시간 수정 지원.
3. 주간 계획: 일~토 7일, 일일 시간·배치 시간·할일 표시. 날짜 상세에서 직접 배치와 날짜별 일일 시간 수정. 실제 마감 전날 완료 목표, 기간 지정 시 시작일 이전 배치 제외. 앞으로 2년까지 주간 계획 조회.
4. 공부 도우미: 과목·개념/문제·질문·사진 입력 및 3단계 공개 UI. 선생님께 질문은 같은 학교 공개 동의 선생님과 개인 대화방을 만들고 글을 전송. 사진은 자동 전달하지 않음.
5. 소통: 학급 초대 코드, 공개 동의 사용자 목록, 개인·그룹 채팅, 선택한 할일 공유, 차단·신고·대화방/학생 학급 나가기.
6. 설정: 프로필·일일 시간·테마·알림 시간·백업·역할 신청. 관리자는 실제 신원을 별도로 확인한 뒤 선생님 승인. 학급 선생님은 반장 지정·공지·시간표 관리.

## 데이터와 개인정보

- 기존 workspace·계정·할일을 삭제하지 않고 필드를 추가하는 방식. 기존 8교시 개인 시간표는 9교시로 표시하며 앞의 8칸 유지.
- 관리자 권한은 기존의 서버 측 고정 사용자 ID를 유지. 이메일 문자열만으로 신규 가입자에게 관리자 권한을 주지 않음.
- 학급은 승인된 선생님/관리자만 만들 수 있음. 초대 코드는 DB에 해시만 저장하고 재발급 시 기존 코드 무효.
- 학생은 초대 코드와 소속 일치·학급 참여 동의가 필요. 소속은 연결 중 임의 변경 불가. 학교를 바꾸면 선생님 승인 상태 초기화.
- 공개 목록은 학급 연결 및 공개 동의가 있는 같은 학교 사용자만. 채팅은 참여자만 조회 가능. 탈퇴/차단 처리 시 서버에서도 접근/발송 제한.
- 일정 공유는 선택한 할일의 제목·분류·과목·마감·기간·소요 시간·중요도·난이도만. 개인 메모·완료량·진행 기록·다른 할일은 전달하지 않음.
- 모든 campus 테이블은 RLS와 PUBLIC 권한 차단. DB URL·나이스 키는 서버 전용이며 브라우저 번들에 포함하지 않음.
- 채팅은 열린 화면에서 약 15초 주기, 게시판/사용자 목록은 활성 화면에서 약 60초 주기로 갱신. 즉시 실시간 통신이나 브라우저 종료 후 푸시를 제공한다고 표시하지 않음.

## AI: 현재 비활성화

- 서버 게이트: `AI_TUTOR_ENABLED=false`. 실제 답변 생성은 사용 불가. 선생님께 질문하기는 사용 가능.
- Vercel AI Gateway 실제 연결 시 카드 등록 요구 오류(customer_verification_required, HTTP 403)를 확인. 결제/자동 충전/유료 전환을 진행하지 않음.
- 사용자가 제공한 Gemini 키로 모델 목록 조회는 성공. 그러나 [Gemini API 약관](https://ai.google.dev/gemini-api/terms)의 Age Requirements에서 18세 미만 대상/이용 가능 앱을 제한하므로 학생용 운영 연결을 중단. 질문·사진을 Gemini에 전송하지 않았으며 해당 키는 배포 환경에 등록하지 않음. 로컬 임시 키 파일도 제거.
- 연결 준비된 구조: 인증 사용자만 호출, 1인 하루 5회·사이트 하루 30회·초기 월 40회, 동시 요청에도 원자적 한도 적용. 실패 요청도 횟수 포함. 같은 사용자의 동일 완료 질문은 저장 결과 재사용.
- 생성 전 고유 ID를 만들고 질문·모델·상태를 저장, 완료 시 답변·토큰·추정 비용 저장. `#tutor/답변ID`는 본인 로그인 후만 조회. 사진 원본은 DB에 보관하지 않는 설계.
- 3단계 공개·저장 답변 재조회 UI 테스트는 **고정 응답을 사용한 UI 테스트**이며 실제 AI 생성 성공 증거가 아님.
- 학생 대상 이용 조건과 개인정보 처리에 맞는 공급자 선택 또는 별도 학교용 계약을 확인한 뒤 켜야 함. 단순 나이 확인 체크박스로 이 앱의 이용 대상을 숨기지 않음.

## 급식과 알림

- `NEIS_API_KEY`: Vercel Production/Preview에 비밀값으로 등록. 학교 이름을 공식 schoolInfo 결과와 정확히 대조해 하나일 때만 조회. 동명 학교는 임의 선택하지 않음.
- 실제 나이스 API에서 2026-09-08 대전과학고등학교 조식·중식·석식 조회 확인. 메뉴의 알레르기 번호 보존. 등록된 메뉴가 없거나 연결이 실패하면 그 사실을 표시.
- 브라우저 알림은 사이트가 열려 있는 동안에만 가능. 절전·종료 상태 전달을 보장하지 않음. 캘린더 파일 내보내기 제공(후속 수정 자동 동기화 없음).
- 학교 교시 시작 시각은 기본 예시이며 개인/선생님이 실제 시간에 맞게 편집해야 함.

## 설치와 검증

`npm ci`, `npm test`, `npm run check`, `npm run build` 후 `npm run dev`.

기존 DB에 `node --env-file=.env.local scripts/migrate-campus.mjs`를 먼저 실행. 신규 테이블과 함수 추가 및 접근 제한만 수행하며 기존 workspace는 수정하지 않음. 정상 서비스 환경에서는 DB 서버 역할만 사용.

로컬 검증: 단위 테스트 130개 통과, 실제 Neon 계정을 사용하는 앱/학급/채팅 검사 40개 통과, 급식·달력 드래그·수동 계획·단계별 답변 UI 등 추가 검사 15개 통과. 12개 동시 한도 요청 중 정확히 5개만 허용되고 거절 요청은 전역 한도를 소모하지 않음을 확인. 테스트용 계정·자료만 삭제했으며 실제 사용자는 수정하지 않음.

공개 운영 전에는 학교의 이용/개인정보 안내와 선생님 확인 절차도 별도로 준비해야 함. 이번 검증이 학교 도입 승인이나 보안 인증을 의미하지는 않음.
