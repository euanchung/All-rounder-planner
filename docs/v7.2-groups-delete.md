# v7.2 — 할일 삭제와 자동 그룹

## 할일 삭제

- 메인·마감 상세·주간 계획의 할일 목록과 수정 화면에서 삭제.
- 제목을 표시한 확인 창에서 취소 가능. 확정 후 메모·진행 기록·직접 배치도 제거하며 자동 계획을 다시 계산.
- 기존 계정별 클라우드 저장 및 저장 충돌 보호 사용. 새로고침 후에도 삭제 유지.
- 이미 공유한 채팅 메시지는 당시 내용의 사본이므로 유지. 삭제한 할일의 신규 공유 요청은 거절.
- 앱 내 삭제 취소 기능은 없으며, 필요한 자료는 삭제 전에 설정에서 백업.

## 자동 그룹

- 기존 관리자 승인 선생님 + 학급 초대 코드 체계를 유지.
- 인증된 학급 연결과 프로필 공개 동의 후 '우리 학교'와 '우리 반' 그룹을 자동 생성/표시. 별도 생성·초대 클릭 불필요.
- 학교 그룹은 같은 인증 학교끼리, 반 그룹은 학교·학년·반이 모두 같을 때 공유. 직접 입력한 미인증 학교 이름만으로 연결하지 않음.
- 여러 사용자의 동시 접속에도 고유 키로 중복 그룹 생성 방지.
- 매 조회·전송·신고마다 현재 소속·공개 여부를 서버에서 확인. 공개 해제나 학급 연결 해제 후 이전 그룹 주소 접근도 거절.
- 자동 그룹의 공개 설정 버튼으로 설정 이동. 공개를 끄면 두 자동 그룹에서 빠짐. 이미 보낸 메시지는 다른 참여자에게 남을 수 있음.
- 그룹 참여만으로 개인 할일·메모를 공유하지 않음. 사용자가 선택한 할일만 메시지로 공유.
- 자동 그룹의 차단은 양방향 메시지 숨김으로 처리. 차단 한 건 때문에 학교 전체 전송을 막지 않음. 기존 개인 대화의 보호 유지.
- 학교·반 변경은 이전 학급 해제 → 프로필 수정 → 새 초대 코드 연결. 교사가 없는 학생은 개인 모드 유지.

## 운영

기존 DB에 `node --env-file=.env.local scripts/migrate-campus.mjs`를 먼저 실행. rooms에 nullable 컬럼 2개와 고유 인덱스만 추가하며 기존 대화와 할일은 삭제하지 않음. 이전 배포와 호환.
