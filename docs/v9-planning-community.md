# v9 — 입력·계획·학교 공유·소통 (2026-09-08)

## 빠른 입력

한 줄마다 날짜, 시간표의 정확한 과목명, 분류, 중요도, 난이도를 인식하고 실제 인식한 단어를 칩으로 표시합니다. 인식된 단어는 제목에서 제외합니다. 목록과 계획에는 과목·분류를 함께 표시하고, 제목이 같아도 과목·세부 분류가 다르면 각각 저장합니다.

- 소요 시간은 반드시 별도로 입력합니다. 2분 스피치·1시간 발표 같은 표현은 소요 시간으로 추출하지 않습니다.
- 프린트·숙제·문제풀이·문제 풀기·학습지·연습문제: 일반 과제.
- 어려움·어려운·고난도 등: 어려움. 쉬움·쉬운·기초 등: 쉬움.
- 중요함·중요·매우 중요·필수 / 안중요·안 중요함·선택·선택사항 등을 구분합니다. 충돌은 경고합니다.
- 여러 줄에서도 각 항목의 소요 시간을 입력해야 합니다. 미입력 항목은 일괄 저장을 막습니다.
- 규칙 기반 분석이며 모든 자연어를 이해하는 AI는 아닙니다. 과목·날짜 충돌은 직접 확인합니다.

## 가능한 빨리 수행하는 계획

정렬은 실제 마감 시각 → 총 소요 시간 내림차순 → 중요도 내림차순 → 난이도 내림차순입니다. 자동 배치는 오늘부터 가능한 앞 날짜를 채웁니다. 사용자가 직접 배치한 시간은 우선 보존합니다.

보통 과제는 한 항목 하루 120분, 어려운 과제는 기본 60분 단위로 나눕니다. 어려운 과제의 하루 합계 기본 한도는 90분입니다. 오늘 컨디션 상은 항목 120분/합계 180분, 하는 항목·합계 30분, 중은 기본값입니다. 이는 부드러운 분할 한도이며, 지키느라 마감을 놓칠 상황에서는 남은 여유에 마감 보호 배치를 합니다. 일일 시간 자체를 초과하지 않습니다. 부족량은 경고합니다.

기존의 마감 전날 완료 목표는 유지합니다. 실제 마감 시각과 완료 목표를 구분합니다. 미래 주에 직접 배치한 시간도 현재 주에 중복 배치하지 않습니다.

## 수업 시각·홈 화면

과목과 날짜가 있으면 해당 날짜의 같은 과목 첫 수업 시작 시각을 마감으로 채웁니다. 같은 날 해당 수업이 없으면 임의 시각을 만들지 않고 안내합니다. 날짜 없이 과목만 있으면 앞으로 2주 내 다음 수업을 찾습니다. 직접 입력한 마감 시각과 시간표에서 선택한 교시는 우선합니다.

수업 마감이 지나면 홈·달력 아래 할일 목록에서 제외합니다. 기록을 자동 삭제하거나 완료 처리하지는 않으며 주간 계획의 관리 목록에 남습니다. 시간표·달력 클릭 결과는 달력 아래에 표시합니다. 오늘/내일 급식은 각각 버튼을 눌러 팝업에서 조회합니다.

제공된 대전과학고 반의 월·수 9교시는 자생, 화 9교시는 동아리로 반영했습니다. 다른 학교나 반에 이 과목을 강제 적용하지 않습니다.

## 학교 공유

첫 등록자는 사진 분석 초안을 검토하거나 직접 학교 일과 시각과 과목을 작성합니다. 다음 회원은 같은 학교 일과를 재사용하고, 같은 학년·반이면 과목 시간표도 재사용합니다. 학교 이름은 정확히 입력해야 합니다.

학교·학급 최초 작성자 또는 해당 학교 승인 선생님, 관리자가 공유 자료를 수정할 수 있습니다. 소속을 입력했다고 다른 사람의 공유 일과를 덮어쓸 수 없습니다. 수정 충돌은 revision으로 차단하고 날짜는 DB date를 문자열로 반환하여 시간대 하루 오차를 막습니다. 사진 AI는 무료 공급자 장애 시 직접 입력으로 이어갈 수 있습니다. 실제 사진 자동 인식 성공은 아직 확인되지 않았습니다.

## 소통·알림

학교/학급 시간표 공유와 사람 목록 공개는 별개입니다. 사람 목록·채팅은 승인 선생님의 학급 초대 코드 및 프로필 공개 동의가 필요합니다. 이름 또는 사용자 ID 검색은 공개에 동의한 같은 학교 목록 안에서 동작합니다. 기존 1:1 대화방을 재사용합니다.

약 10초 간격 및 탭 복귀·온라인 복귀 시 새 메시지를 확인합니다. 홈에서도 읽지 않은 수를 볼 수 있고, 대화방에서 읽으면 서버에 기록합니다. 읽은 시각은 DB의 정밀도를 보존합니다. 보내기 재시도에는 식별자를 사용해 중복 저장을 방지합니다. 기존 역할·차단·초대·공유 제한은 유지합니다.

설정에서 기기별 새 채팅·공지 웹 푸시를 켤 수 있습니다. 서버 전용 VAPID 키, 검증된 HTTPS 푸시 주소, 소속·공개 동의·차단 확인을 적용하고, 알림 본문에는 대화의 실제 내용이나 회원 정보를 넣지 않습니다. 유료 요금제나 자동 충전은 켜지 않았습니다. 실제 기기의 OS 알림 수신 확인은 남아 있으며 절전·브라우저 종료 정책에 따라 지연될 수 있습니다. 지정 시각 개인 할일 알림은 여전히 앱이 열린 동안 동작하며 서버 예약 발송이라고 표시하지 않습니다.

## 계정 정리·검증

사용자의 요청으로 검증 계정 45개와 승인받은 선생님 계정 1개를 삭제했습니다. 실제 DB 재조회에서 일반 회원 0명, 관리자 1계정임을 확인했습니다. 관리자 개인 할일과 설정은 보존했습니다. 이전 테스트 정리의 이메일 대소문자 불일치가 원인이었으며, 이후 검증에는 실제 회원을 생성하지 않는 로컬 대체 데이터를 사용합니다. 현재 이메일·비밀번호 가입/로그인을 유지하며 Google OAuth 버튼을 새로 추가하지 않았습니다.

검증: 단위 테스트 181개, 이전 단계 실제 DB/브라우저 통합 검사 44개, 추가 요구사항은 실제 회원 생성 없는 로컬 UI 검사 14개 통과. 실제 나이스 오늘·내일 급식 각각 3식 조회 성공. 실사용자 세션을 대신 로그인하지 않았습니다. 학교 사진 AI와 실제 기기 웹 푸시는 위 제한을 참고하세요.

배포 전 additive DB 마이그레이션을 적용합니다: `node --env-file=.env.local scripts/migrate-campus.mjs`. 새 서버 환경 변수는 `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`이며 비밀키는 클라이언트/저장소에 넣지 않습니다.
