# 메타시간표 — All-rounder planner

## 현재 버전: v7.2 학교 연결형

[v7.2 변경 안내](docs/v7.2-groups-delete.md): 등록된 할일 삭제와, 학급 인증·공개 동의 후 같은 학교/같은 반 그룹 자동 연결을 추가했습니다.

로그인 필수인 6개 화면(메인, 할일 추가, 주간 계획, 공부 도우미, 소통, 설정)으로 개편했습니다. 첫 로그인에서 학교·학년·반·요일별 일일 시간을 설정합니다. 관리자 승인 선생님과 초대 코드로 학급을 연결하며, 연결하지 않아도 개인 계획을 사용할 수 있습니다.

현재 기능·검증 범위·운영 제한은 [v7 안내](docs/v7-campus.md)를 우선 참고하세요. 아래 v5/v6 설명은 이전 버전 개발 기록입니다. **v7.1은 Google Gemini 직접 연결로 개념 설명과 사진 문제의 3단계 풀이를 제공합니다.** 서버 전용 키·로그인·전송 동의·사용량 제한·본인 답변 저장을 적용합니다. 공급자의 학생 대상 이용 제한은 해결된 것으로 간주하지 않으며 자세한 운영 위험은 v7 안내에 기록했습니다. 급식도 서버 전용 나이스 키로 실제 조회합니다.

한 줄로 할일을 적고, 실제 남은 시간과 작업량을 확인하는 한국어 웹앱입니다. 이전 이름은 변생 레이더입니다. 기존 계정과 저장 키를 유지하여 기존 기록을 그대로 읽습니다.

## 용어와 실시간 계산 (v5)

- 공부: 시험·수행평가 대비, 복습·예습 등의 학습. 과제: 기한이 있는 학교·학원의 보고서 작성·발표 자료 만들기·숙제. 할일 = 공부 + 과제.
- 일일 시간: 하루에 공부·과제에 쓸 수 있는 시간. 소요 시간: 총 필요한 시간. 남은 시간 = 소요 시간 − 진행 시간. 마감까지의 시간과 구별합니다.
- 이전 혼합 study 분류는 제목으로 재분류하고, 이후 수동으로 선택한 분류는 kindVersion으로 보존합니다. 준비물·구매 등 생활 항목은 목록에 유지하되 학업 시간 배치에서 제외합니다.
- 마감까지는 실시간으로 표시하고, 계획·과부하·일일 시간 여유는 분이 바뀌거나 탭에 돌아오면 갱신합니다. 입력창을 다시 만들지 않아 초안과 포커스를 보존합니다. 시간 경과만으로 작업량을 완료 처리하지 않습니다.
- 오늘 배치 가능한 시간 = min(일일 시간 − 오늘 진행 기록, 자정까지 실제 남은 분). 마감 시각이 있으면 그 시각 이전으로 추가 제한합니다. 시간표의 실제 자유 시간 구간까지 아는 것은 아니므로 보수적으로 일일 시간을 조정해야 합니다.
- 공지 자동 대조는 무료·기기 내 한국어 규칙/제목 유사도이며 학습형 AI가 아닙니다. 빠진 필드·메모·진행 기록·직접 계획은 유지하고 명시된 변경만 반영합니다. 모호한 연결이나 여러 날짜는 사용자 확인이 필요합니다.

## 가장 빠른 사용법 (v5)

1. 첫 화면에 `내일까지 물리 보고서 제출 60분` 입력 → Enter. 필수 확인 양식 없이 바로 등록합니다.
2. 여러 할일은 한 줄씩 붙여 넣고 한 번에 등록합니다. 날짜 제목은 다음 항목에 적용하며, 각 줄에 적힌 날짜가 우선합니다. 준비물·장소처럼 라벨이 있는 후속 줄은 앞 할일에 연결합니다. 모호한 단톡방 문장 구조를 완벽히 이해한다고 보장하지 않으므로 일괄 확인 화면에서 제목·날짜·분·분류·과목을 고칠 수 있습니다.
3. `계산기 챙기기`, `체육복 가져오기`는 준비물, `공책 사기`, `문제집 구매하기`는 구매로 분류합니다. 시간이 없으면 공부·과제30분·생활 항목10분을 **추정**이라고 표시합니다.
4. 할일의 수정 버튼으로 사소한 변경을 하고, 메모/더보기에 짧은 진행 메모를 저장합니다. 장소·비용·준비물 등 세부 필드는 선택사항입니다. 공지 비교에서는 연결할 과제를 고르지 않고 복사·붙여넣기하면 기존 항목 대조/신규 추가를 자동 제안합니다. 비슷한 후보·취소·날짜 충돌만 확인하고 한 번에 반영합니다.
5. ‘나의 계획’ → ‘내가 직접 계획 / 특정 날짜 시간 바꾸기’에서 특정 할일을 원하는 날짜에 우선 배치하거나, 해당 날짜의 일일 시간을 추가·감소·지정합니다. 요일 기본값은 바꾸지 않습니다.

‘~까지’는 해당 날짜도 작업 가능한 마감입니다. 내일 제출하되 오늘 끝내야 한다면 `오늘까지 물리 보고서 완료 60분`처럼 완료할 날짜를 씁니다. 현재 시각과 명시한 마감 시각을 반영하며, 날짜만 쓰면 다음 날 00:00까지로 해석합니다. 수업·휴식의 시간대는 자동 파악하지 않습니다.

이름과 로고를 메타시간표로 변경하고 흰색·보라색·짙은 글자 중심으로 정리했습니다. 상세 분석은 접어 두고, 남은 시간은 7일 한 줄, 계획은 7일씩 두 줄로 표시합니다. 휴대폰에서도 남은 시간 7칸은 한 화면에서 보며, 상세 계획은 가로로 스크롤할 수 있습니다.

## 메일 및 알림 범위

- 이메일·비밀번호 가입과 로그인을 유지하며 가입 이메일 확인 화면/OTP 요청 경로를 제거했습니다. 이메일 인증 없이 실제 가입·로그인·개인 클라우드 저장이 동작하는 것을 확인했습니다.
- 소유자가 명시적으로 지정한 기존 계정의 불변 user ID에 관리자 권한을 한 번 연결했습니다. 이메일 확인 상태를 위조하지 않았고, 이메일 일치만으로 자동 승격하는 로그인 코드는 제거했습니다. 계정을 삭제하고 같은 이메일로 재가입해도 관리자 권한이 자동 승계되지 않습니다. 개인 이메일/ID는 저장소에 싣지 않습니다.
- 비밀번호 재설정은 별개의 소유 확인이 필요하여 기존 메일 복구를 유지합니다. 메일 미수신 원인은 해결하지 못했으므로 복구에는 여전히 제한이 있습니다. 가입 인증 제거를 메일 전달 문제 해결로 표현하지 않습니다.
- 설정의 브라우저 알림은 사용자가 켜야 하며 사이트가 열려 있는 동안만 동작합니다. 마감30분 전과5분 타이머 종료를 안내합니다. 시각 없는 마감은09:00 기준입니다. 기기 절전·브라우저 종료·권한 미허용 때는 보장되지 않습니다. 서비스워커는 알림 표시에만 쓰며 인증 데이터 캐시·요청 가로채기를 하지 않습니다.
- 사이트 종료 후 알림이 필요하면 .ics 파일을 캘린더에 가져올 수 있습니다. 개인 과제명·날짜가 포함되며30분 전 알람을 넣습니다. 캘린더 앱의 알림 지원·설정에 따라 다르고, 앱의 이후 변경은 자동 동기화되지 않습니다. 중복 가져오기에 주의하세요.
- 별도 예약 서버를 통한 상시 Web Push는 미구현입니다. iPhone은 홈 화면 웹앱 추가와 사용자의 알림 허용이 필요합니다. 유료 서비스·예약 발송 서비스를 추가하지 않았습니다.

참고: [Neon 메일 설정](https://neon.com/docs/auth/production-checklist#email-provider), [Neon OTP](https://neon.com/docs/auth/guides/email-verification), [iOS Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/).

공개 사이트: https://all-rounder-planner.vercel.app

Vercel Hobby + Neon Free를 사용합니다. 사이트 접속·예제 체험에 Vercel 로그인은 필요하지 않습니다. 내 기록을 다른 기기에서 이어 쓰려면 앱 계정으로 로그인합니다. GitHub main 변경은 Vercel에 자동 배포됩니다.

## 시작하기

Node.js 22 이상. 연결된 프로젝트에서 환경 변수를 먼저 내려받습니다.

```sh
npm ci
vercel env pull .env.local --yes
node --env-file=.env.local scripts/migrate.mjs
npm run build
npm run dev
```

로컬 주소: http://localhost:4173
프런트엔드 수정 후 npm run build, 서버 수정 후 개발 서버를 재시작합니다.

```sh
npm test
npm run check
npm run build
```

필수 서버 환경 변수: DATABASE_URL, NEON_AUTH_BASE_URL. ADMIN_EMAIL은 더 이상 런타임 자동 권한 부여에 사용하지 않습니다.
Neon Marketplace가 데이터베이스와 인증 주소를 공급합니다. 관리자 이메일은 서버 설정에만 넣습니다. 비밀키와 .env 파일은 커밋하지 않습니다. 클라이언트 번들에는 공개 인증 URL만 포함됩니다.

## 기능

1. 이메일 회원가입·로그인·로그아웃, 비밀번호 재설정. 가입 이메일 확인은 요구하지 않습니다.
2. 첫 로그인 사용법과 개인 설정: 이름, 선택적 학교·학년·반, 월~일 일일 시간, 선택적 5일×8교시 시간표.
3. 요일별 일일 시간으로 14일 역산 계획. 0분인 날은 작업을 배치하지 않습니다. 시간표는 참고 정보이며 일일 시간에서 다시 차감하지 않습니다.
4. 공지 원문 분석 → 모호한 부분 확인 → 변경 비교 → 사용자 승인 → 과제·계획 반영.
5. 화면 뒤로가기와 브라우저 뒤로가기. 작성 중 공지·검토·설정 초안은 해당 탭의 sessionStorage에 보관해 페이지 이동·새로고침에 복원됩니다. 탭을 닫거나 로그아웃하면 초안은 사라질 수 있습니다.
6. 승인한 과제·계획·설정은 계정별 클라우드 저장. 상단에 저장 중/완료/실패/충돌 상태를 구분합니다.
7. 로그인 전 기존 localStorage 기록은 보존하며, 명시적 확인 후 계정으로 가져옵니다. 원본은 지우지 않습니다. JSON 백업 v1/v2 지원.
8. 예제 공간은 실제 기록과 분리됩니다.
9. 소요 시간 − 완료 시간 = 남은 시간. 오늘을 포함한 날짜 수로 하루 필요 시간을 계산합니다. 중요도(1~3), 난이도(1~5), 마감, 작업량으로 설명 가능한 0~100점 우선순위를 표시합니다.
10. 전체 미래 마감의 누적 작업량을 요일별 일일 시간과 비교하여 최초 부족 마감, 최대 부족분, 추가 확보 시간의 평균을 안내합니다. 개별 과제는 가능해도 여러 과제가 겹치면 경고합니다. 단순히 수면·휴식을 줄이도록 권하지 않습니다.
11. 실행 도우미: 5분 시작 타이머, 실제 진행 시간 기록·취소, 문제 3개씩 시작하기, 문제별 미풀이/막힘/해결 상태, 막힌 이유별 가이드와 구체적인 질문 초안. 승인한 기록은 계정에 저장하고, 문제별 미저장 메모와 타이머는 해당 탭의 임시 초안으로 유지합니다.
12. 이차방정식 검산: 정수 계수 -10000~10000 범위에서 판별식·근의 공식·실근/중근/복소수 해, 퇴화한 일차식·상수식을 구분합니다. 임의 문제를 이해하는 AI 풀이 도구가 아닙니다.

## 작업량 계산 규칙

- 남은 날짜는 현재 날짜와 마감일의 달력 차이. 오늘 마감은 D-day, 작업 가능한 날은 오늘 포함 1일입니다. 지난 마감·미정 마감은 하루 필요 시간을 숫자로 꾸미지 않습니다.
- 우선순위 = 반올림(35 / (1 + max(남은 날짜, 0) / 3) + min(남은 분 / 240, 1) × 25 + (중요도 − 1) / 2 × 20 + (난이도 − 1) / 4 × 20). 미정 마감의 긴급도는 0점, 완료/남은 작업 0이면 총 0점입니다. 학습된 점수나 성적·성실성 평가가 아닙니다.
- 역산 계획의 시간 확보는 빠른 마감 우선으로 유지하고, 같은 날짜에 배치된 작업 및 전체 목록은 우선순위 점수순으로 표시합니다. 점수 때문에 빠른 마감의 시간을 늦은 과제가 빼앗지 않습니다.
- 오늘 저장한 진행 기록은 남은 시간과 오늘 일일 시간에서 함께 차감합니다. 다음 주 같은 요일에는 차감하지 않습니다. 과제 수정 창에서 직접 입력한 완료 시간은 과거 누적 시간으로 취급하며 오늘 기록에 더하지 않습니다.
- 타이머는 자동 완료 판정이 아닙니다. 사용자가 실제 시간을 입력해야 반영됩니다. 문제 해결 상태도 작업 시간과 별도로 기록하여 단순 문제 개수로 소요 시간을 단정하지 않습니다.
- 기존 v1/v2 과제는 종전의 minutes를 남은 작업으로 해석합니다. 새 기록에는 totalMinutes/completedMinutes를 함께 보관하고 minutes를 그 차이와 일치시킵니다. 서버에서도 범위와 일관성을 검사합니다. 새 DB 테이블이나 유료 서비스는 추가하지 않습니다.
- 최대 문제 200개, 할일당 진행 기록 200회. 문제 수를 줄일 때 삭제를 확인합니다. 진행 기록을 취소하면 실제 시간 계산도 되돌립니다. 시간을 유지하려면 기록을 삭제하지 말고 과제 완료 기능을 사용하세요.

## 설문에서 기능으로

사용자는 여러 고교 유형의 친구들에게 조사했으며 수학의 많은 과제량·높은 난이도, 문제풀이 미루기, 귀찮음·어려움을 주요 문제로 전달했습니다. 이에 작업량 가시화, 작은 시작, 막힘 분류와 질문 초안을 구현했습니다. 응답자 수와 원자료가 제공되지 않아 비율·통계를 만들어 넣지 않았습니다. 설문은 문제 필요성의 근거이지 앱 효과의 검증 결과가 아닙니다. 효과는 이후 동일 사용자·기간의 시작 지연 시간, 계획 대비 실제 작업, 마감 준수, 체감 불편을 비교해 별도 확인해야 합니다.

## 권한과 저장 안전성

- 서버는 Neon 전용 JWKS로 JWT 서명·만료를 검증하고 공급자의 사용자 레코드를 확인합니다.
- 클라이언트가 제출한 이메일·역할·사용자 ID로 권한을 부여하지 않습니다.
- 소유자가 승인한 기존 계정의 ID를 public.radar_admin에 연결합니다. 이메일 입력값으로 자동 승격하지 않습니다. 관리자 페이지는 회원 수·첫 설정 완료 수만 보여주며 개인 과제·학교·시간표를 노출하지 않습니다.
- 모든 과제 읽기·쓰기는 검증된 사용자 ID로 제한합니다. 다른 탭에서 계정이 바뀐 경우 X-Radar-User 일치 검사로 잘못된 계정에 저장하지 않습니다.
- 데이터베이스에 RLS를 켜고 PUBLIC 접근을 회수합니다. 데이터베이스 비밀번호를 브라우저에 전달하지 않습니다.
- 서버 revision을 비교해 오래된 쓰기를 409로 거절합니다. 저장 실패 내용은 해당 계정·탭에 임시 보관하고, 충돌 시 백업 후 서버 저장본을 다시 불러오도록 안내합니다.
- 비밀번호·이메일 인증번호는 앱 임시 초안에 저장하지 않습니다. 로그인·이메일 전송은 Neon Auth가 처리합니다.

## 범위와 한계

앱 내부 분석은 결정론적 한국어 표현 규칙이며, 학습된 모델이나 LLM이 아닙니다. 유료 AI API를 사용하지 않습니다. 분석 자체는 기기에서 실행하지만 **로그인 후 승인하여 저장한 공지 원문과 설정은 Neon 데이터베이스로 전송됩니다**.

날짜가 여러 개면 임의 선택하지 않습니다. 상대 날짜는 공지 작성일 기준이며, 새 공지에서 항목이 빠져도 취소로 간주하지 않고 기존 값을 확인받습니다. 작업 시간은 사용자가 입력한 추정치입니다.

계획은 14일·하루 단위이며 마감 당일까지 작업할 수 있다고 가정합니다. 마감 시각 전 실제 여유 시간은 직접 확인해야 합니다. 미정 마감·14일 이후 마감은 배치하지 않습니다. 빠른 마감과 같은 마감의 중요도를 우선합니다.

최대 과제 300개·과제별 이력 100개·저장 요청 약 4MB 제한. 무료 서비스의 사용량 한도가 있으며 유료 업그레이드 없이 무제한 운영을 보장하지 않습니다. Neon Auth SDK는 베타 버전을 사용하므로 잠금 파일과 회귀 테스트를 유지합니다.

서버 기반 상시 푸시 알림·카카오톡 수집·외부 공지 자동 수집·시간표 자동 연동은 지원하지 않습니다. 위에서 설명한 브라우저 열린 동안의 알림·캘린더 내보내기는 지원합니다.

직접 배치한 시간은 자동 계획보다 우선합니다. 그로 인해 다른 마감이 어려워질 수 있어 부족 경고를 확인해야 합니다. 날짜의 가용량이 줄거나 마감이 바뀌면 직접 계획의 충돌을 표시하고 가용량을 초과 배치하지 않습니다. 실제 공부를 기록하면 직접 배치 시간도 앞 날짜부터 소진하며, 진행 기록 취소로 돌아온 작업은 자동으로 다시 배치합니다.
