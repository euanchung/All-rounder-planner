# 변생 레이더 — All-rounder planner

공지의 변화가 과제와 계획에 미치는 영향을 확인하는 한국어 웹앱입니다. 아이디어 1(과제 레이더)과 2(변생앱)를 하나의 흐름으로 구현한 첫 버전입니다.

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
npm test
npm run check
npm run build
```

로컬 주소: http://127.0.0.1:4173

## 핵심 흐름

1. 원문과 공지 작성일을 입력하고 새 과제로 등록합니다.
2. 날짜·과목·분량·제출 방식 등 해석 초안을 확인하고 고칩니다.
3. 수정 공지가 오면 연결할 과제를 선택하고 새 원문만 넣습니다.
4. 변경 항목과 근거 표현, 모호한 부분과 질문 초안을 확인합니다.
5. 마감과 남은 작업 시간을 직접 확인한 뒤 변경을 승인합니다.
6. 하루 가용 시간을 기준으로 14일 역산 계획과 배치하지 못한 시간을 확인합니다.

예제 체험은 실제 공간과 분리되어 있습니다. 새로고침하면 예제 변경은 사라집니다. 물리 수정 예제에서 남은 작업 시간을 120분에서 240분으로 변경하면 작업량 증가의 영향을 확인할 수 있습니다.

## 범위와 한계

- AI로 개발했지만 앱 내부 분석은 **결정론적 한국어 표현 규칙**입니다. 학습된 모델이나 LLM이라고 주장하지 않습니다. 유료 AI API, 서버 데이터베이스, 외부 요청이 없습니다.
- 모든 자연어를 이해하지 않습니다. 날짜 후보가 여러 개이면 마감을 임의 선택하지 않습니다. 미정·취소·변경 표현도 확인 대상으로 표시합니다.
- 상대 날짜는 사용자가 입력한 공지 작성일을 기준으로 해석합니다. 연도가 없는 날짜는 그 작성일의 연도를 사용합니다.
- 준비물·대상·장소 등은 `준비물: ...` 형태를 권장합니다. 날짜·분량 등이 달라도 작업 시간은 자동 추정으로 덮어쓰지 않습니다.
- 새 공지에서 항목이 사라졌다고 취소로 간주하지 않습니다. 기존 값을 유지한 상태로 확인받으며 사용자가 지울 수 있습니다.
- 역산 계획은 14일간 하루 단위로, 마감 당일까지 작업 가능하다고 가정합니다. 마감 시각 이전에 실제 시간이 있는지는 확인해야 합니다. 수업 시간표 자동 연동·시간대별 스케줄링은 없습니다.
- 계획의 시간은 사용자가 입력한 남은 작업량입니다. 작업 중간 진척은 수정 화면에서 남은 시간을 바꿉니다.
- 빠른 마감부터 시간을 확보하고, 각 작업을 마감일부터 거꾸로 배치합니다. 같은 마감에서는 중요도가 높은 작업이 우선합니다. 미정 마감과 14일 이후 마감은 배치하지 않습니다.
- 최대 과제 300개, 과제별 이전 기록 100개. 브라우저 저장 공간에 따라 실제 저장 한도는 더 작을 수 있습니다.
- 데이터는 **해당 기기·브라우저·사이트 주소의 localStorage**에만 남습니다. 다른 기기와 동기화되지 않으며 브라우저 데이터 삭제 시 사라집니다. JSON 백업을 별도로 보관하세요.
- 공지 원문은 서버로 전송되지 않습니다. 사이트 접속 자체에 필요한 일반 웹 요청은 호스팅 제공자에게 전달됩니다.
- 알림 푸시, 카카오톡 수집, 외부 URL 자동 수집, 자동 메시지 발송은 지원하지 않습니다.

## Vercel Git 연결

- Framework Preset: Other
- Root Directory: 저장소 루트
- Build Command: `npm run build`
- Output Directory: `dist`
- 유료 API 환경 변수 불필요
- GitHub 저장소 연결 후 production branch의 push에 따라 자동 배포
- 공개 **프로덕션 주소**를 로그인하지 않은 창에서 확인해야 합니다. preview 주소의 보호 설정과 구분하세요.

## 파일 구성

- `src/engine.js`: 해석·비교·역산 계획·백업 검증
- `src/app.js`: 한국어 화면과 사용자 승인, 브라우저 저장
- `src/style.css`: 데스크톱·모바일 화면
- `tests/engine.test.mjs`: 엔진 회귀 테스트
- `scripts`: 로컬 실행과 정적 빌드
- `vercel.json`: 배포 설정과 기본 보안 헤더

개인 공지, 백업 파일, 비밀키는 저장소에 올리지 마세요. 예제 데이터는 시연용 가상 데이터입니다.
